# Калькулятор с поддержкой р-ичных чисел

Реализация калькулятора на JavaScript для работы с р-ичными числами. Архитектура проекта позволяет в будущем добавить поддержку других типов чисел (комплексные числа, дроби).

## Текущие возможности

- Работа с р-ичными числами (системы счисления от 2 до 16)
- Основные арифметические операции:
  - Сложение (+)
  - Вычитание (-)
  - Умножение (*)
  - Деление (/)
- Поддержка дробных и отрицательных чисел
- Настраиваемая точность вычислений
- Память для хранения промежуточных результатов
- Обработка ошибок и некорректного ввода

## Архитектура

Проект построен на основе модульной архитектуры, что позволяет легко расширять функциональность:

### Основные компоненты:

- `ADT_Control` - основной контроллер калькулятора, координирующий работу всех компонентов
- `TPNumber` - реализация р-ичных чисел с поддержкой различных систем счисления
- `TPNumberEditor` - редактор для ввода чисел, обеспечивающий корректность ввода
- `TMemory` - память калькулятора с двумя состояниями (включена/выключена)
- `ADT_Proc` - процессор для выполнения арифметических операций
