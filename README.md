# Калькулятор с поддержкой разных систем счисления

Реализация калькулятора на JavaScript с поддержкой различных систем счисления и расширяемой архитектурой.

## Возможности

- Работа с числами в разных системах счисления (от 2 до 16)
- Основные арифметические операции (+, -, *, /)
- Поддержка дробных и отрицательных чисел
- Настраиваемая точность вычислений
- Память для хранения промежуточных результатов
- Обработка ошибок и некорректного ввода

### Основные компоненты:

- `ADT_Control` - основной контроллер калькулятора
- `TPNumber` - реализация р-ичных чисел
- `TPNumberEditor` - редактор для ввода чисел
- `TMemory` - память калькулятора
- `ADT_Proc` - процессор для выполнения операций
